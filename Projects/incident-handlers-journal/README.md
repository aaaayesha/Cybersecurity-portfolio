# Incident Handler’s Journal

This repository contains a completed incident handler’s journal documenting
incident investigations, cybersecurity tool usage, and professional reflections.
The entries align with the NIST Incident Response Lifecycle and demonstrate
practical incident response documentation skills.

## Contents
- Incident investigations documented using the 5 W’s
- Network and security tool usage (Wireshark, tcpdump, VirusTotal)
- Reflections on incident detection, response, and learning outcomes
