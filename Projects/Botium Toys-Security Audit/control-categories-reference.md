# Control Categories Reference

## Administrative / Managerial Controls
Administrative controls address the human and policy aspects of cybersecurity. These controls define responsibilities, access, and procedures that govern how data and systems are protected.

Examples evaluated in this audit include:
- Least privilege
- Password policies
- Access control policies
- Separation of duties
- Disaster recovery planning

## Technical Controls
Technical controls are system-based protections that prevent, detect, or correct security incidents.

Examples evaluated in this audit include:
- Firewalls
- Antivirus software
- Intrusion detection systems (IDS)
- Encryption
- Backup solutions

## Physical / Operational Controls
Physical controls limit unauthorized physical access to assets and facilities.

Examples evaluated in this audit include:
- Facility locks
- CCTV surveillance
- Fire detection and prevention systems
