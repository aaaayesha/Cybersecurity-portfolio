# Security Recommendations

To reduce risk and improve Botium Toys’ security posture, the following controls and compliance best practices should be implemented as a priority:

- Enforce least privilege and separation of duties
- Implement encryption for cardholder data and PII/SPII
- Establish disaster recovery and backup procedures
- Deploy an intrusion detection system (IDS)
- Strengthen password policies and implement a centralized password management system
- Formalize legacy system monitoring and maintenance schedules
- Classify assets to better align controls with risk

## Expected Impact
These actions would significantly improve compliance with PCI DSS, GDPR, and SOC requirements and reduce the likelihood of security incidents and regulatory penalties.
