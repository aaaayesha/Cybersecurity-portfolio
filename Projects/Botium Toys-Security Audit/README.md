# Botium Toys – Internal IT Security Audit

## Overview
This project documents a simulated internal IT security audit for a fictional company, Botium Toys. The audit was completed as part of the Google Cybersecurity Professional Certificate and follows the NIST Cybersecurity Framework (CSF).

The audit assesses the organization’s current security posture, identifies risks to critical assets, evaluates existing administrative, technical, and physical controls, and reviews compliance with industry and regulatory standards.

## Objectives
- Review and define audit scope and goals
- Identify and document IT-managed assets
- Assess existing security controls and gaps
- Evaluate compliance with regulatory requirements
- Develop prioritized recommendations to reduce risk

## Frameworks & Standards
- NIST Cybersecurity Framework (CSF)
- Payment Card Industry Data Security Standard (PCI DSS)
- General Data Protection Regulation (GDPR)

## Control Categories
Security controls were evaluated across three categories:
- Administrative/Managerial controls
- Technical controls
- Physical/Operational controls

Each control was assessed by control type (preventative, detective, corrective, or deterrent) to support defense-in-depth and risk mitigation.

## Key Deliverables
- Controls and compliance checklist
- Risk assessment summary
- Security recommendations and remediation guidance

## Skills Demonstrated
- Internal IT audit methodology
- Risk assessment and control evaluation
- Compliance analysis (PCI DSS, GDPR, SOC concepts)
- Application of NIST CSF
- Security documentation and reporting
- GRC (Governance, Risk, and Compliance) fundamentals

## Disclaimer
This project is based on a fictional scenario and is intended for educational and portfolio purposes only.
